## 观察与定位

1. 哪个时刻卡？是否可稳定复现？
2. Animation Hitches 是 commit hitch 还是 render hitch？是否可能是静止页面主线程阻塞？
3. Time Profiler 中最明显的函数叫什么？调用者是谁？是否在 Main Thread？
4. CPU 时间耗在哪里？有没有线程等待或文件 I/O？
5. 优化前后是否同一台设备、相同条件对比？

## 面试总结

先用 Animation Hitches 确认卡顿时间，再用 Time Profiler 缩小时间范围，检查主线程热点函数。通过故障版和优化版的对照，验证同步任务、Cell 配置成本或大图处理对性能的影响，并复测卡顿与内存。
